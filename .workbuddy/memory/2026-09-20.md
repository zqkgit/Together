## 工作室入驻链路走查（iOS + 后端）

端到端确认 iOS「工作室入驻」页逻辑：
- `StudioAuthViewController`（真目录 `Together_ios/Together_ios/Modules/Mine/`）三态渲染：pending→审核中页、rejected→表单+驳回原因回显、其他→表单；双入口 Mine/Studio 端"我的"经 `getRoleApplyStatus("studio")` 决策
- 提交 → `AuthService.submitRoleApply(role:"studio")` → `POST /auth/role/apply` → `roleApplyService.submitRoleApply`（写 `studio_applications`，status 0 待审/1 通过/2 驳回，已生效/待审拦截）
