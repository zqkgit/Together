# 2026-09-22 工作日志

## 修复「待办事项」页（StudioTodoViewController）UI 全挤在一起
- **现象**：工作室端「经营概览 → 待办事项 → 全部 ›」进去的页面，三行内容全部挤在导航栏下方、卡片几乎看不见。
- **页面归属**：该页是 `Modules/Studio/StudioTodoViewController.swift`（**不是**占位页；概览页 `didTapAllTodos` 现在 push 的是它）。行点击分别进 `StudioRefundViewController(initialStatus: 0/1)`；结算行只 toast（Web 端处理）。
- **根因（关键）**：`StudioTodoCell` 的卡片**高度没有任何约束确定** —— `card` 只钉 `top/bottom = contentView ± 6`，而内部 `iconBox` 只用 `centerY + 40x40`、`titleLabel.top = iconBox.top + 2`、`detailLabel.bottom = iconBox.bottom - 2`，**没有一条约束链把卡片撑起来**。`rowHeight = automaticDimension` 只能算出塌缩高度 → 行高≈0、三行重叠在一起，卡片（高度 0）不可见，而 iconBox/文字溢出到卡片外仍然可见。
- **修复**：
  1. 卡片给**显式高度** `cardHeight = 76`（上下各留 6 → 行高 88），`estimatedRowHeight` 同步改 88；
  2. 文字改成明确链条：`titleLabel.top = iconBox.top + 2` → `detailLabel.top = titleLabel.bottom + 4` → `detailLabel.bottom = iconBox.bottom - 2`，横向都 `<= badgeLabel.leading - 8`；
  3. 右侧控件（chevron / badgeLabel）**先 addSubview 再被左侧 label 引用**（SnapKit 铁律）；
  4. `sectionHeaderTopPadding = 0`（iOS 15+ plain style 首个 section 前默认留 22pt，与概览页同一个坑）。
- ⚠️ **新踩的坑：角标位置用 `lessThanOrEqualTo` 会飘**。把 `badgeLabel.trailing` 写成 `lessThanOrEqualTo(chevron.leading).offset(-8)` 后，横向位置**欠定**，实际渲染跑到卡片中间（实测红像素 x≈194，应在 x≈346）。**定位用的约束必须用等式**，`lessThanOrEqualTo` 只适合给文字留出「不要越界」的上界。
- **验证方法**：
  - 先用 `NSLog` 在 `BaseViewController.viewDidAppear` 临时打印当前 VC 类名 → 确认「全部」进的是 `StudioTodoViewController`（此前误以为是占位页）；
  - 再用临时启动参数 `--preview-todos` 直达该页截图；
  - 我读不了 PNG，用 **Pillow 逐行分类渲染 ASCII 缩略图**目视布局（`W`=白卡 / `+`=浅色块 / `#`=文字 / `R`=红色角标）+ **按颜色聚簇定位角标**。
  - 修复后实测：白卡 y 118–190 / 202–276 / 292–362，行间 ~12–18pt（圆角导致检测偏小），角标稳定在右侧 x≈336–352；模拟器日志无 Auto Layout 冲突。
- 临时钩子（`--preview-overview`、`--preview-todos`、`BaseViewController` 的 TEMP-DEBUG）已全部删除，最终 BUILD SUCCEEDED，无参数启动 PID 78634。
