# YIQI 设计系统 v2.0 ·「温暖手作」

> 方向：Notion 骨架（暖中性 + 衬线标题 + whisper 边 + 多层微阴影） × Airbnb 亲和（大圆角 + 暖调重量） × 木色记忆点（画架/纸张/陶土）
> 评审依据：impeccable（AI Slop Test + Nielsen 10 启发式，原 22/40 → 目标 32/40）
> 适用：Ardot 文件 721116261735448（平台端 6 屏 + 工作室端 8 屏）

---

## 一、设计原则（4 条铁律）

1. **暖调优先** —— 任何中性色都不得是纯灰/纯白/纯黑，一律带黄褐 undertones（纸张感）。
2. **绿色克制** —— 深松绿只用于「操作」与「选中」，不再铺满整屏；大面积交由暖米白承担。
3. **木色是记忆点** —— 木色（画架）+ 陶土橙（颜料）是「艺启 = 儿童艺术」的视觉签名，成对出现。
4. **衬线只在"标题位"** —— 屏幕标题、品牌名、区块主标题用衬线；数据、正文、标签一律无衬线（可读性）。

| **屏幕标题 / 品牌名 / 区块主标题** | `Noto Serif SC` | Bold (700) | 美术馆人文气质（Ardot 已确认可用） |

**阴影公式（Notion 式多层微阴影，用暖黑不用纯黑）**
```

layer2: rgba(43,38,33,0.03) 0 2px 6px
```
强调卡（陶土橙/木色）用同色系阴影：
```

layer2: rgba(140,89,46,0.05) 0 2px 6px
```

## 五、图标系统

- **尺寸**：功能图标统一 36×36 圆角方块容器（圆角 10），内置 20×20 线性图标。
- **风格**：1.5px 描边、圆头端点（stroke-linecap: round）、圆角连接。
- **配色**：容器底为色系 tint（木色 `#F5EBDC` / 绿色 `#E9F1EA`），图标描边为对应主色。
- **状态联动**：待处理 → 木色/陶土色调；已完成 → 绿色调。
- **禁止**：emoji 当功能图标（🧾📝🖼️ 等，风格不统一、渲染不一致、显业余）。

## 十、App 组件原子规范（mobile）

> 适用屏：App 端 46 屏（375×812 逻辑尺寸，状态栏 46px）。以下为可复用原子，Ardot 与 `app-prototype.html` 均应遵循。

### 10.1 框架
- 状态栏：高 46px，顶贴，时间 / 信号 / 电量两端对齐，字重 600 / 13px，`text-primary`
- 内容区：单一纵向 wrapper，`gap` 垂直间距，底部 `padding-bottom:72px` 给 tab bar 留白；禁止空 spacer 撑高
- 卡片：白底 `surface` + `border` 1px whisper 边 + `radius 16` + 双层暖阴影（`--shadow-sm`）
- 主按钮：高 46–48px，`radius 12`，`green-primary` 底 + `text-on-dark` 字，双层暖阴影；禁用态降透明度

### 10.2 底部 Tab Bar（Shell-B 通用）
- 容器：高 62px，底贴，`surface` 底 + `border-top` 1px，内边距 12/8
- 4 tab 等分：`首页 / 课程 / 动态 / 我的`，每 tab 纵向 图标(23) + 文字(10, SemiBold 600)
- 选中态：`green-primary` 圆角 pill（radius 26）+ `text-on-dark` 字；未选中 `text-muted`
- 图标用线性 SVG（20–23px，1.5px 描边），禁用 emoji

### 10.3 表单与输入
- 输入框 / 选择行：白底 `surface` + `border` 1px + `radius 14`，内边距 14/16，placeholder 用 `text-muted`
- 文本域：白底 + whisper 边 + `radius 12`，最小高 96
- 分段控件：两等宽 pill，`radius 9999`，选中 `green-primary` 底

### 10.4 列表与菜单
- 列表行：白底卡内每行 `gap 12`，左图标容器 34–38（tint 木色 / 绿浅）+ 标题（14, 600）+ 右箭头 `text-muted`
- 菜单组：白底 `radius 18` 分组，组间 `margin 14`

### 10.5 头像 / 徽标
- 头像：圆角 `radius 14–20`（方头像更有手作感），木色 / 绿浅 tint 占位
- 状态徽标：pill `radius 9999`，语义色 tint 底 + 同色字（success / warn / danger / info），须颜色 + 文字双重编码

### 10.6 数字与强调
- 关键金额 / Hero 数字：`clay` 陶土橙 或 `green-primary`，衬线 `Noto Serif SC` Bold，22–34px
- 次要数字：`text-secondary`，无衬线
