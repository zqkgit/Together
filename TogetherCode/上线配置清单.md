### OSS 对象存储（图片统一走 OSS，上传接口已按 OSS 写好逻辑）

| 配置项 | 含义 | 填写说明 |
|---|---|---|
| `OSS_REGION` | 地域 | 如 `oss-cn-hangzhou`（阿里云 OSS 控制台查看） |

| `OSS_ACCESS_KEY_SECRET` | AccessKey Secret | 同上 |
| `OSS_BUCKET` | 存储桶名 | 如 `yiqi-uploads` |

> 说明：App / 小程序 / Web 展示图片时用 `OSS_PUBLIC_URL + 上传路径` 拼 URL；后端上传逻辑已实现，配置后即可用。

### 接口加密（RSA 传会话密钥 + AES-256-GCM）

| 配置项 | 含义 | 填写说明 |
|---|---|---|
| `API_ENCRYPT_ENABLED` | 加密开关 | `true` 开启（生产）；四端已接齐，可直接开 |
| `API_ENCRYPT_PRIVATE_KEY` | RSA 私钥（base64） | 已生成并写入 `.env`；密钥对在 `Together_api/config/api_enc_*.pem`，**私钥严禁外泄/提交 git** |

> 协议：请求头 `X-Enc-Key`（RSA-OAEP 加密的会话密钥）+ `X-Enc-Nonce`（防重放）+ `X-Enc-Timestamp`（±5 分钟）；POST/PUT/DELETE 的 body 与响应 data 用 AES-GCM 加密；上传/WebSocket 接口豁免。
> 接入状态：**四端全部已接** —— 后端中间件、iOS（`APICrypto.swift`）、小程序（`services/crypto.ts`，node-forge）、Web（`utils/crypto.ts`，浏览器 Web Crypto）。四端互连已联调验证通过；**上线统一把各端开关置 `true` 即可**。

## 六、配置顺序建议（按依赖排）

1. **买/绑定域名 + HTTPS**（所有端都要用它）
2. **阿里云 OSS**：建 Bucket、RAM 子账号、绑定域名 → 填后端 `OSS_*` + 小程序 `OSS_DOMAIN`
3. **微信生态**：小程序 AppID/AppSecret、商户号、API v3 密钥、回调域名 → 填后端 `WX_*`
4. **极光**：控制台建应用、上传 APNs 证书 → 填后端 `JPUSH_*` + iOS `jpushAppKey`
5. **友盟**：控制台建 iOS 应用 → 填 iOS `umengAppKey`
6. **小程序后台**：配置合法域名、订阅消息模板
7. **后端安全**：改 `JWT_SECRET`、云数据库/Redis 密码
8. **iOS 上架**：切生产环境、`jpushIsProduction=true`、补隐私政策声明
